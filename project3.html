2.1 自定义图传

在 Jetson NX 上部署 ROS 2 作为底层通信框架，实现了极致的高频采集与低延迟压缩传输：

  • 高频图像采集：通过 C++ 驱动海康工业相机（MVS SDK），实现高达 160fps 的裸流采集，发布高频图像话题。
  • 高鲁棒性弹道检测：在 160fps 的超高帧率下同步运行弹道追踪算法。采用帧差法结合亮度匹配，并引入震动补偿与热力图机制（有效抑制静态边缘的假阳性），实现高精准的弹道轨迹捕获。
  • 硬编码与压缩：为适应串口带宽限制，调用 GStreamer x264 实现 H.264 硬件编码。将高帧率视频流极致压缩，并打包为 291 字节的固定大小 ROS 2 消息（VideoPacket），通过串口直连下位机 MCU 进行数据传输。

2.2 自定义客户端

为解决官方客户端信息展示僵化、操作繁琐的痛点，采用现代化前端技术栈，从零重构了一套高度定制化的自定义客户端：

  • 全平台兼容与协议接管：基于 Electron + Vue 框架开发，利用 Chromium 引擎与 Node.js 底层能力，实现一份代码无缝编译打包为 Windows / macOS / Linux 跨平台桌面应用。底层完美解析比赛裁判系统协议，100% 覆盖官方客户端的基础数据展示与链路功能。
  • 高自由度模块化 HUD：引入前端拖拽与响应式布局技术，开发了高度自由的 HUD组件。操作手可根据个人赛场习惯，对小地图、底盘姿态、弹药余量等 UI 组件进行全屏自由拖拽、层级调整与动态缩放，并且支持重载和导入json配置。
  • 按键自定义映射功能：可以自由绑定按键，添加许多实用功能，实现一键买弹，一键复活。
